
# Financy Server

GraphQL API for the Financy project.

---

## 🏁 First Time Setup

If you are new to programming, start from the [main README](../README.md) for a step-by-step guide to running the full project (backend + frontend).

---

## ⚙️ Local Development (Backend Only)

1. **Install dependencies**
	```bash
	pnpm install
	```
2. **Copy environment variables file**
	```bash
	cp .env.example .env.dev
	# Edit .env.dev if needed (see below for required variables)
	```

3. **Prepare database and start server**
	```bash
	pnpm dev:db:generate   # generate Prisma client
	pnpm dev:db:migrate    # create/apply migrations
	pnpm dev:db:seed       # (optional) seed the database
	pnpm dev               # start the backend server
	```

API endpoint: http://localhost:3333/graphql

---

## 📝 Required Environment Variables

Set these in `.env.dev`:

- `PORT` (optional, default `3333`)
- `NODE_ENV` (optional, default `production`)
- `DATABASE_URL` (required, SQLite format `file:`)
- `JWT_SECRET` (required)
- `JWT_REFRESH_SECRET` (required)
- `COOKIE_SECRET` (required)
- `WEB_URL` (required, e.g. `http://localhost:5173`)

Example for development:
```
DATABASE_URL="file:./prisma/dev.db"
```

## 📂 Project Structure

- `src/resolvers`: GraphQL operations
- `src/services`: business logic
- `src/models`: GraphQL models
- `src/prisma`: Prisma schema, migrations, and database access
- `src/middlewares`: authentication middleware
- `src/test`: test setup and factories

---

## 🧪 Scripts & Testing


Common scripts:

```bash
pnpm dev                # start server in development mode (.env.dev)
pnpm dev:db:generate    # generate Prisma client
pnpm dev:db:migrate     # create/apply migrations
pnpm dev:db:seed        # run seed via Prisma in development
pnpm dev:db:studio      # open Prisma Studio in development
pnpm prod:db:generate   # generate Prisma client for production
pnpm prod:db:migrate    # apply migrations in production (.env.prod)
pnpm build              # build production bundle
pnpm test               # run tests once (.env.test)
pnpm test:watch         # run tests in watch mode (.env.test)
pnpm test:coverage      # run tests with coverage (.env.test)
```

Test coverage includes:
- resolvers
- services
- auth middleware
- authorization and error scenarios

Test runs use `.env.test`. Ensure it includes all required variables.
