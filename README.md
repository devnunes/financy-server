# Financy Server

GraphQL API for the Financy project, built as part of a final postgraduate project at Rocketseat Faculty of Technology.

## Goal

Provide authentication and per-user financial data management with strict data isolation between accounts.

## Stack

- Node.js + TypeScript
- Fastify
- Apollo Server + TypeGraphQL
- Prisma ORM
- SQLite
- Vitest
- Biome


> **Todas as operações de autenticação, transações e categorias exigidas pelo desafio estão implementadas e disponíveis na API.**
## Current GraphQL Surface

### Authentication

- `signUp`
- `signIn`
- `signOut`
- Session via HTTP cookie
- Auth middleware for private resolvers

### User

- `me`
- `getUser`
- `updateUser`

### Transactions

- `createTransaction`
- `getTransactions`
- `updateTransaction`
- `deleteTransaction`
- `getTransactionSummary`

### Categories

- `createCategory`
- `getCategories`
- `updateCategory`
- `deleteCategory`
- `getCategoriesSummary`

## Environment Configuration

Environment variables validated in `src/env.ts`:

- `PORT` (optional, default `3333`)
- `NODE_ENV` (optional, default `production`)
- `DATABASE_URL` (required, SQLite format `file:`)
- `JWT_SECRET` (required)
- `JWT_REFRESH_SECRET` (required)
- `COOKIE_SECRET` (required)
- `WEB_URL` (required for explicit credentialed CORS origin; e.g. `http://localhost:5173`)

## Local Development Setup

```bash
pnpm install
cp .env.example .env.dev
# Ensure .env.dev contains DATABASE_URL, JWT_SECRET, JWT_REFRESH_SECRET, COOKIE_SECRET, and WEB_URL
pnpm dev:generate
pnpm dev:migrate
pnpm dev
```

API endpoint: `http://localhost:3333/graphql`

## Scripts

```bash
pnpm dev            # start server in development mode (.env.dev)
pnpm dev:migrate    # create/apply Prisma migrations in development
pnpm dev:generate   # generate Prisma client in development
pnpm dev:studio     # open Prisma Studio in development
pnpm seed           # run seed script in development
pnpm test           # run tests once (.env.test)
pnpm test:watch     # run tests in watch mode (.env.test)
pnpm test:coverage  # run tests with coverage (.env.test)
```

## Tests

Test coverage includes:

- resolvers
- services
- auth middleware
- authorization and error scenarios

Test runs use `.env.test`. Ensure it includes `DATABASE_URL`, `JWT_SECRET`, `JWT_REFRESH_SECRET`, `COOKIE_SECRET`, and `WEB_URL`.

## Project Structure

- `src/resolvers`: GraphQL operations
- `src/services`: business logic
- `src/models`: GraphQL models
- `src/prisma`: Prisma schema, migrations, and database access
- `src/middlewares`: authentication middleware
- `src/test`: test setup and factories

## Notes

- `schema.graphql` is generated by TypeGraphQL from registered resolvers.
- Category resolvers are registered and available in the published GraphQL schema.
